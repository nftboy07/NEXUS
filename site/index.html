Architecture

  1. A provider streams a block, log or pending transaction.
  2. Ingestion validates it and tags network and source.
  3. The event is normalized into NexusNormalizedEvent.
  4. A deduplication key prevents double processing.
  5. It is queued durably on Redis Streams.
  6. Specialized workers decode, enrich, correlate and classify.
  7. Rules and scores decide what is interesting.
  8. Selected events go to the AI investigation agent.
  9. Evidence-backed findings are stored and delivered.
  10. Checkpoints allow gap-free recovery after outages.

Failover

Reconnect with backoff, switch provider, read the last checkpoint, backfill the gap over HTTP, deduplicate, resume.

Reorgs

Block hashes and parent hashes are stored; removed logs invalidate and recompute derived state.

Stack

TypeScript + viem, Python + FastAPI, PostgreSQL, Redis Streams, Next.js, Docker Compose.

Run it locally

Needs Docker with Compose. Free publicnode RPCs work for both chains.

# 1. configure
git clone https://github.com/nftboy07/NEXUS.git
cd NEXUS
cp .env.example .env
# set NEXUS_API_KEY and DASHBOARD_PROXY_TOKEN;
# RPC URLs default to publicnode in the smoke run

# 2. start every service
docker compose up -d --build

# 3. open
# dashboard  http://localhost:3000  (sign in with DASHBOARD_PROXY_TOKEN)
# API        http://localhost:8000/health
# end-to-end smoke test (fresh volume)
docker compose down -v
bash scripts/smoke.sh

# unit tests, per service
cd services/evm_listener && npm run typecheck && npm test
cd services/mev_analyzer && .venv/bin/python -m pytest
cd apps/dashboard && npm run lint && npm test && npm run build

Safety rails

Read-only

No private keys, signing, trading or transaction submission. EXECUTION_ENABLED stays false.

Evidence first

Findings cite transaction hashes, block numbers, contracts and timestamps. The AI agent may not invent activity.

No secrets in code

Credentials come from the environment only. The dashboard proxy refuses anonymous callers.
